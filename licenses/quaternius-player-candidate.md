# Quaternius player candidate assets

Active comparison files:
- `public/assets/quaternius/player/male_ranger.glb`
- `public/assets/quaternius/player/male_head.glb`

Retained comparison/rollback files while the player body is being chosen:
- `public/assets/quaternius/player/male_peasant.glb`
- `public/assets/quaternius/player/hair_simpleparted.glb`

Original asset authorship: Quaternius.
Source packs: Modular Character Outfits - Fantasy and Universal Base Characters.
License: Creative Commons Zero v1.0 Universal (CC0-1.0).

These runtime GLBs are optimized web derivatives produced from the same CC0 Quaternius packs by the public Genesara character prep pipeline. They are pinned here to Genesara commit `90c166baa14682eedf1358c6c0a6e40e91765495`; the original Quaternius packs remain the authoritative art source and license source.

`male_ranger.glb` was re-inspected before activation: 1,617,696 bytes, SHA-256 `513203b0eadc4849aeba0e24effd5dc85b0b072ddc0d0b14b6242c0ba1847eea`, ten skinned meshes, one 65-joint universal skeleton. Its authored hood is part of the body asset, so the separate hair module is intentionally inactive for this comparison.
