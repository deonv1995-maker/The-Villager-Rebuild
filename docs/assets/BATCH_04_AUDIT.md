# Batch 04 Asset Audit — Wildlife candidates

Date: 2026-08-29

This batch reviews the three additional animal packs supplied during Foundation 0.3.1.

## Animal QiwiiPack

- Supplied license states the models may be used free in personal or commercial projects.
- Reselling the same or modified assets is not permitted.
- Credit is not required.
- The pack provides very small individual low-poly FBX models sharing a compact texture atlas.
- `Pig.fbx` is selected for the current Day 1 hunt presentation test because its proportions/style are closer to the KayKit-led world than the procedural boar.
- Only the selected Pig model, shared texture and license are imported into production. The full archive is not shipped.
- The selected Pig has no confirmed animation clips, so presentation motion remains lightweight procedural movement around the static model.

Decision: **primary current Day 1 hunt presentation candidate; broader pack remains optional supporting wildlife.**

## EverythingLibrary Animals 002

- Supplied archive contains a large combined FBX and Blend file rather than isolated production-ready animal models.
- The archive supplied in this batch does not contain an embedded license/provenance file.
- It includes potentially useful broader wildlife, but extracting and shipping a single animal should wait until source/license provenance is explicitly recorded.

Decision: **reference / future curated wildlife source; do not import yet.**

## Oh Deer a Little Family

- Supplied readme states CC BY-NC-SA.
- The non-commercial restriction conflicts with a commercial production game.
- Pack includes Buck, Button Buck, Doe and Fawn with a walk-cycle option, but licensing makes them unsuitable for production use here.

Decision: **rejected for production.**

## Foundation 0.3.1 selection

Use the Qiwii Pig as the Day 1 hunt style test while keeping animal gameplay generic. This is not a permanent requirement that the opening animal remain a pig; it is a production-quality asset test that avoids coupling hunting rules to a specific species.
